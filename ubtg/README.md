# 🌐 UBTG Tutorial Site — "Начало работы & Облачный Хост"

Интерактивный сайт-руководство для пользователей Telegram-юзербота **UBTG**, выполненный в современном стиле **Microsoft Fluent Design 2 (Windows 11 Mica & Acrylic)**.

---

## ✨ Возможности и разделы сайта

- ☁️ **Акцент на Облачном Хостинге (@aswer_ubtg_host_bot)**:
  - Выделенный презентационный блок с аватаркой бота и скриншотами интерфейса подписки (`assets/`).
  - Интерактивная галерея скриншотов с увеличением по клику (Lightbox).
  - Подробное описание защищенного режима `--host` (отключение `.terminal` и локального `.install` ради безопасности, при сохранении полного доступа к GitHub каталогу `.ghinstall`).
- ⚖️ **Интерактивная таблица сравнения**: Наглядное сравнение "Облачный Хост vs Свой Сервер (Self-Host)".
- 🛠️ **Самостоятельная установка**: Подробные руководства для Windows / macOS / Linux, VPS серверов и Android (Termux).
- 🎨 **Современный Fluent Design**: Эффект слюды (Mica), акриловые панели, мягкие неоновые градиенты, глубокая тёмная тема (Fluent Dark).
- 📱 **Полная мобильная адаптация под смартфоны**:
  - Адаптивное выдвижное меню-шторка (Mobile Drawer) с анимацией и затемнением фона.
  - Оптимизированные сенсорные зоны (Touch Targets 44px+), адаптивная сетка тарифов и карточек.
  - Горизонтальный скролл табов и таблиц сравнения с подсказками для свайпа.
  - Поддержка safe-area-insets и защита от авто-масштабирования на iOS Safari.
- 🔍 **Интерактивный каталог команд**: Живой поиск и фильтрация команд с пометками доступности на хосте.
- ⚙️ **Интерактивный CLI Генератор**: Визуальный конфигуратор параметров запуска юзербота с мгновенным формированием готовой команды.
- 📋 **Копирование кода в 1 клик**: Интерактивные кнопки с микроанимацией и Fluent Toast-уведомлениями.

## 🚀 Как открыть и просмотреть сайт

### Вариант 1: Запуск локального веб-сервера
В терминале перейдите в папку сайта и запустите встроенный HTTP-сервер Python:
```bash
cd /home/ubuntu/ubtg/userbot-tg/tutorial_site
python3 -m http.server 3000
```
После этого откройте в браузере: **`http://127.0.0.1:3000`**

### Вариант 2: Прямое открытие файла
Откройте файл `tutorial_site/index.html` в вашем браузере:
```bash
# Linux
xdg-open tutorial_site/index.html

# macOS
open tutorial_site/index.html
```
