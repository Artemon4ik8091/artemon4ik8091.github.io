Мастерство настройки

Как настраивать модули под себя через .cfg

Каждый модуль может иметь свои настройки (например, кастомный текст для .info, время задержки или приветственное сообщение).

1

Посмотреть все настройки

.cfg list

Выведет список всех сохраненных параметров для каждого модуля.

2

Посмотреть настройки одного модуля

.cfg get module_info

Покажет только те ключи, которые принадлежат выбранному модулю.

3

Изменить параметр

.cfg set module_info media_path https://...

Умный парсер сам поймет текст, числа или значения True/False и перезагрузит бота для применения!
