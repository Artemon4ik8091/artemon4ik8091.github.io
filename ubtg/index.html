Раздел 1 • Архитектура

Что такое UBTG и как он работает?

UBTG (Userbot Telegram) — это инструмент для автоматизации вашего Telegram-аккаунта. В отличие от обычных чат-ботов, юзербот выполняет команды прямо от вашего имени через префикс точки (например, .ping или .info).

🚀

Команды на лету

Вы просто пишете команду с точкой (.команда) в любой чат или «Избранное». Юзербот моментально редактирует ваше сообщение, выводя результат.

🤖

Собственный Бот-Ассистент

Юзербот сам автоматически создаёт для вас Telegram-бота через @BotFather. Это даёт интерактивные инлайн-кнопки в сообщениях и личные системные уведомления.

📦

Умные модули

Ставьте готовые плагины из каталога одной командой .ghinstall. Если модулю нужны библиотеки, бот сам скачает их через pip и перезагрузится.

🛡️

Защита от спамбана

В ядро встроен Rate Limiter и перехватчик FloodWait, которые не позволят зафлудить Telegram API и защитят аккаунт от временных ограничений.

Раздел 2 • Подготовка

Шаг 0: Получение ключей Telegram API

Для самостоятельного запуска на своём сервере требуются два параметра: app_id (число) и hash_id (строка). Получить их можно бесплатно за 2 минуты на официальном сайте Telegram.

1

Авторизуйтесь на my.telegram.org

Откройте официальный портал разработчиков Telegram: https://my.telegram.org. Введите ваш номер телефона с кодом страны (например, +79991234567) и подтвердите вход кодом из Telegram.

2

Перейдите в раздел «API development tools»

В главном меню кликните по пункту API development tools. Если вы заходите впервые, появится форма создания приложения.

3

Заполните форму приложения

Заполните поля формы произвольными данными:

  • App title: например, MyTelegramUB
  • Short name: например, myuserbot
  • Platform: Desktop / Other

Нажмите синюю кнопку Create application.

4

Скопируйте `App api_id` и `App api_hash`

На странице отобразятся ваши персональные данные:

Пример ключей 
# Ваши API данные (пример):
App api_id:   28471923           (число из 7-8 цифр)
App api_hash: "b1a9e8f4c2d3a1e0b5f8a7e2c9d01234" (строка из 32 символов)
⚠️
Правило безопасности: Никогда не передавайте ваш hash_id и файл userbot.session третьим лицам! Эти данные дают доступ к вашему аккаунту.

Самостоятельная установка и запуск

🤖 Открыть @aswer_ubtg_host_bot

Убедитесь, что у вас установлены Python 3.9+ и Git. Откройте Терминал (Linux/macOS) или PowerShell (Windows) и выполните:

Bash / Terminal 
# 1. Клонируем репозиторий
git clone https://github.com/Artemon4ik8091/userbot-tg.git
cd userbot-tg

# 2. Устанавливаем базовые зависимости (Telethon, QRCode, psutil)
pip install -r requirements.txt

# 3. Запускаем мастер настройки юзербота
python3 userbot.py
💡
Рекомендация: Рекомендуется использовать виртуальное окружение: python3 -m venv venv && source venv/bin/activate перед установкой зависимостей.

Раздел 4 • Авторизация

Веб-Мастер первого запуска и вход по QR

При первом самостоятельном запуске юзербот автоматически поднимет красивый локальный веб-сервер авторизации на порту 8080.

🌐

1. Откройте веб-страницу

Перейдите в браузере по адресу:
http://127.0.0.1:8080
(или http://IP_вашего_сервера:8080)

🔑

2. Введите API ключи

Вставьте полученные на Шаге 0 app_id и hash_id. При необходимости настройте прокси (HTTP / SOCKS5 / SOCKS4).

📱

3. Сканируйте QR в Telegram

На экране появится QR-код. Откройте в Telegram на смартфоне: Настройки → Устройства → Подключить устройство и наведите камеру.

🤖

4. Имя бота-ассистента

После входа задайте желаемый логин для встроенного бота или оставьте поле пустым — ядро сгенерирует бота автоматически через @BotFather!

💡
Консольный режим без браузера: Если у вас чистый сервер без веб-доступа, запустите бот с флагом python3 userbot.py --no-web — ключи и ASCII QR-код для сканирования отобразятся прямо в терминале.

Раздел 9 • Сервер

Настройка автозапуска 24/7 (Self-Host)

Если вы используете собственный Linux VPS, настройте службу systemd, чтобы бот работал непрерывно после закрытия SSH-сессии:

/etc/systemd/system/userbot.service 
[Unit]
Description=UBTG Telegram Userbot Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/userbot-tg
ExecStart=/usr/bin/python3 userbot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Раздел 10 • Вопросы и ответы

Часто задаваемые вопросы (FAQ)

Ответы на самые частые вопросы пользователей юзербота и сервиса хостинга:

☁️ В чём преимущество хостинга в @aswer_ubtg_host_bot? ▼

Бот @aswer_ubtg_host_bot позволяет запустить юзербота без владения сервером и без ввода консольных команд. Вы просто сканируете QR-код в боте — и ваш юзербот уже работает 24/7. Также обновления ядра накатываются автоматически.

🛡️ Почему на хостинге отключены команды .terminal и .install? ▼

На облачном хостинге активирован защитный флаг --host. Он блокирует выполнение произвольного shell-кода сервера и установку непроверенных скриптов из чата, защищая аккаунты пользователей и стабильность инфраструктуры. При этом все проверенные модули из официального каталога GitHub (.ghinstall) работают без ограничений!

🛡️ Могут ли заблокировать мой аккаунт за использование юзербота? ▼

В UBTG встроена надежная защита от спамбана: минимальный интервал между командами и автоматический перехват задержек FloodWait. При обычном использовании команд и полезных модулей риск бана минимален. Однако избегайте агрессивного спама и массовых рассылок по чужим чатам.

🔄 Как обновить юзербот, когда выйдет новая версия? ▼

На собственном сервере напишите команду .update now в любом диалоге Telegram. Юзербот сам подтянет обновления из GitHub, обновит зависимости и мгновенно перезагрузится. На облачном хосте бот обновляется автоматически.

🤖 Что делать, если бот-ассистент перестал отвечать на кнопки? ▼

Напишите команду .resettoken. Юзербот автоматически свяжется с @BotFather, сгенерирует новый токен бота, обновит конфигурацию и перезапустит процесс.

🔐 Где сохраняются мои данные и сессия? ▼

При самостоятельной установке все файлы хранятся в вашей папке:
• userbot.session — авторизационная сессия Telegram.
• core_conf.json — API ключи и токен ассистента.
• Global_config.json — персональные настройки модулей.
