Руководство разработчика модулей

Архитектура UBTG построена на независимых плагинах. Вам никогда не требуется модифицировать ядро (userbot.py). Создайте файл .py, используйте реестр registry.py, и установщик автоматически подхватит его, скачав все нужные зависимости.

1. Архитектура и расположение файлов

Модули и компоненты юзербота разделены по директориям в зависимости от их назначения:

Директория / Файл Назначение Особенности
modules/ Пользовательские модули Устанавливаются через .install или .ghinstall. Можно свободно удалять через .uninstall.
system_modules/ Системные модули ядра 🔒 Любой файл в этой папке автоматически помечается system=True. Защищен от удаления пользователем.
init_modules/ Pre-Auth модули инициализации Выполняются до авторизации Telegram клиента (веб-мастер авторизации QR/Web, настройка прокси).
registry.py Центральный реестр модулей Экспортирует декораторы @register_cmd, @register_bg, @register_callback, функции send_inline, get_config.
💡 Режим хостинга (--host)

При запуске с флагом --host юзербот в целях безопасности отключает модули локального терминала (terminal.py) и ручного установщика файлов.

2. Жизненный цикл ядра

  1. Pre-Auth Wizard: Сбор конфигурации через Веб-интерфейс или консоль (API ID/Hash, QR-логин).
  2. Инициализация Telethon: Авторизация в Telegram и запуск фонового Event Loop.
  3. Инициализация встроенного Telegram-бота: Создание бота через @BotFather, включение Inline-режима и сохранение токена в core_conf.json.
  4. Динамическая загрузка плагинов: Сканирование system_modules/ и modules/, валидация синтаксиса и регистрация команд.
  5. Запуск фоновых тасок: Старт всех корутин, зарегистрированных через @register_bg().

3. Метаданные модуля (set_module_meta)

Для корректного отображения в команде .help и управления правами модуль должен задать метаданные в начале файла:

python 
from registry import set_module_meta, register_cmd

set_module_meta(
    name="Мой Модуль",
    desc="Описание функций плагина для справки .help",
    system=False  # True защитит модуль от удаления через .uninstall
)

4. Создание команд (@register_cmd)

Команды вызываются префиксом . (точка). Функция команды обязательно должна быть асинхронной (async def) и принимать ровно 3 аргумента:

Аргумент Тип Описание
client TelegramClient Экземпляр клиента Telethon. Доступ ко всем методам API Telegram.
event events.NewMessage.Event Событие вашего отправленного сообщения.
args str Строка текста, переданная после команды (без префикса и имени команды).
python 
@register_cmd("say", desc="Печатает текст от твоего имени. Юзай: .say <текст>")
async def say_cmd(client, event, args):
    if not args:
        return await event.edit("❌ Укажи текст: `.say Привет`")
    
    # event.edit() редактирует исходное сообщение
    await event.edit(f"🗣 {args}")

5. Зависимости и автоустановка библиотек

Если вашему модулю требуются сторонние пакеты PyPI (например requests, Pillow, aiohttp), укажите в начале файла специальную директиву:

python 
# requires: requests pillow bs4

Встроенный установщик (gh_installer.py / installer.py):

  • Автоматически парсит комментарий # requires:.
  • Вызывает pip install в фоновом подпроцессе.
  • Перехватывает ModuleNotFoundError при динамическом импорте и докачивает недостающие библиотеки на лету.
  • Бесшовно перезагружает ядро для применения в чистом контексте памяти.

6. Разработка с Inline-кнопками ядра

Встроенный Telegram-бот ядра позволяет отправлять сообщения с интерактивными инлайн-кнопками прямо от вашего лица в любые группы и чаты.

python (Инлайн кнопки) 
from telethon import Button, errors
from registry import register_cmd, register_callback, send_inline

@register_cmd("menu", desc="Открыть интерактивное меню")
async def menu_cmd(client, event, args):
    buttons = [
        [
            Button.inline("🔥 Кнопка 1", b"mymod_btn1"),
            Button.inline("⚙️ Кнопка 2", b"mymod_btn2")
        ],
        [Button.inline("❌ Закрыть", b"mymod_close")]
    ]
    
    await send_inline(
        client=client,
        chat_id=event.chat_id,
        text="🌟 **Интерактивное меню плагина**\nВыберите действие:",
        buttons=buttons,
        reply_to=event.reply_to_msg_id
    )
    await event.delete()

@register_callback("mymod_btn1")
async def on_btn1(event, data):
    await event.answer("Нажата кнопка 1!", alert=True)

@register_callback("mymod_close")
async def on_close(event, data):
    await event.delete()
⚠️ Защита от MessageNotModifiedError

При редактировании инлайн-сообщения (await event.edit(...)) всегда оборачивайте вызов в try...except errors.MessageNotModifiedError: await event.answer(), если содержимое сообщения может не измениться.

7. Фоновые процессы (@register_bg)

Используются для авто-статусов, чекеров и таймеров. Запускаются асинхронно параллельно ядру.

python (Background loop) 
import asyncio
from registry import register_bg

@register_bg()
async def my_background_task(client):
    while True:
        try:
            # Ваша фоновая логика здесь
            pass
        except Exception as e:
            print(f"[MyMod BG Error]: {e}")
        
        # ОБЯЗАТЕЛЬНО: асинхронный сон! Никаких time.sleep()!
        await asyncio.sleep(60)

8. Система Global_config и команда .cfg

Позволяет сохранять настройки модуля в единый Global_config.json и управлять ими через команду .cfg set.

python (Config API) 
from registry import init_config, get_config, set_config

# Инициализация дефолтов в начале файла
init_config(__name__, {
    "delay": 5,
    "reply_text": "Привет!",
    "auto_delete": True
})

@register_cmd("checkcfg", desc="Проверить значение конфига")
async def check_cfg_cmd(client, event, args):
    delay = get_config(__name__, "delay", 5)
    text = get_config(__name__, "reply_text", "Default")
    await event.edit(f"Задержка: {delay} сек, Текст: {text}")

9. Шпаргалка по Telethon в обработчиках

Действие Метод Telethon
Изменить текущее сообщение await event.edit("Новый текст")
Удалить команду await event.delete()
Отправить новое сообщение следом await event.respond("Текст")
Получить реплай на чужое сообщение reply = await event.get_reply_message()
Скачать медиа/файл из реплая path = await reply.download_media(file="downloads/")
Отправить файл / фото в чат await client.send_file(event.chat_id, "file.jpg", caption="...")

10. Бесшовная перезагрузка (restart_userbot)

Если модуль изменил системные параметры ядра или скачал новые библиотеки, вызовите restart_userbot:

python 
from registry import restart_userbot

await restart_userbot(
    client=client,
    chat_id=event.chat_id,
    message_id=event.id,
    custom_text="🎉 **Модуль успешно применил настройки и перезапущен!**"
)

11. Защита от спамбана и Rate Limiter

  • 0.3 секунды — минимальный интервал между параллельными вызовами команд ядра.
  • FloodWaitError Handling — ядро перехватывает таймауты от серверов Telegram и отправляет сервисное уведомление в ЛС владельца через функцию send_bot_notification().
python 
from registry import send_bot_notification

# Отправит уведомление владельцу в ЛС через личного бота ядра
await send_bot_notification("⚠️ **Событие в модуле:** Задача успешно завершена!")

12. Полный пример готового модуля

Готовый к установке файл module_counter.py с инлайн-кнопками и обработкой кликов:

python (module_counter.py) 
import time
from telethon import Button, errors
from registry import register_cmd, set_module_meta, send_inline, register_callback

set_module_meta("Счетчик", "Интерактивный инлайн-счетчик с кнопками")

counters = {}

@register_cmd("counter", desc="Запустить инлайн-счетчик")
async def counter_cmd(client, event, args):
    cid = f"c{int(time.time() * 1000)}"
    counters[cid] = 0

    buttons = [
        [
            Button.inline("➖ Минус", f"cnt_dec_{cid}".encode()),
            Button.inline("➕ Плюс", f"cnt_inc_{cid}".encode())
        ],
        [Button.inline("🔄 Сброс", f"cnt_reset_{cid}".encode())]
    ]

    await send_inline(
        client,
        event.chat_id,
        "🔢 **Инлайн Счетчик**\n\nТекущее значение: `0`",
        buttons=buttons,
        reply_to=event.reply_to_msg_id
    )
    await event.delete()

@register_callback("cnt_inc_")
async def on_inc(event, data):
    cid = data.replace("cnt_inc_", "")
    if cid in counters:
        counters[cid] += 1
        await _update_ui(event, cid)

@register_callback("cnt_dec_")
async def on_dec(event, data):
    cid = data.replace("cnt_dec_", "")
    if cid in counters:
        counters[cid] -= 1
        await _update_ui(event, cid)

@register_callback("cnt_reset_")
async def on_reset(event, data):
    cid = data.replace("cnt_reset_", "")
    if cid in counters:
        counters[cid] = 0
        await _update_ui(event, cid)

async def _update_ui(event, cid):
    val = counters[cid]
    buttons = [
        [
            Button.inline("➖ Минус", f"cnt_dec_{cid}".encode()),
            Button.inline("➕ Плюс", f"cnt_inc_{cid}".encode())
        ],
        [Button.inline("🔄 Сброс", f"cnt_reset_{cid}".encode())]
    ]
    try:
        await event.edit(f"🔢 **Инлайн Счетчик**\n\nТекущее значение: `{val}`", buttons=buttons)
    except errors.MessageNotModifiedError:
        await event.answer()
